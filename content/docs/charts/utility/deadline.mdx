## Usage

`Deadline` marks a due date or point of no return: a vertical line at `date`, plus a region that extends right — to `endDate` or the plot edge — and fades out. Place it as a child of `LineChart`, `AreaChart`, `ComposedChart`, `CandlestickChart`, or a vertical `BarChart` with date rows. It renders in the underlay layer, behind series.

```tsx
import { LineChart } from "@/components/charts/line-chart"
import { Line } from "@/components/charts/line"
import { Grid } from "@/components/charts/grid"
import { Deadline } from "@/components/charts/deadline"
import { ChartTooltip } from "@/components/charts/tooltip/chart-tooltip"
import { XAxis } from "@/components/charts/x-axis"

;<LineChart data={data}>
  <Grid horizontal />
  <Deadline date={new Date(2026, 9, 15)} label="Due Oct 15" />
  <Line dataKey="scope" />
  <Line dataKey="completed" />
  <XAxis />
  <ChartTooltip />
</LineChart>
```

The colour defaults to `var(--color-destructive-foreground)`. The fade gradient is pinned to the region's data coordinates, so it stays in place while you brush or pan. On bar charts the line sits on the left edge of the first column on or after `date`.
