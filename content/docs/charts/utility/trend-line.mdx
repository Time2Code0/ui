## Usage

`TrendLine` fits a straight line through one series (`dataKey`) using linear least squares and draws it across the full data range. Place it as a child of `LineChart`, `AreaChart`, `BarChart` (vertical or horizontal), or `ComposedChart` — **after** the series so it draws on top.

```tsx
import { LineChart } from "@/components/charts/line-chart"
import { Line } from "@/components/charts/line"
import { Grid } from "@/components/charts/grid"
import { TrendLine } from "@/components/charts/trend-line"
import { ChartTooltip } from "@/components/charts/tooltip/chart-tooltip"
import { XAxis } from "@/components/charts/x-axis"

;<LineChart data={data}>
  <Grid horizontal />
  <Line dataKey="value" />
  <TrendLine dataKey="value" />
  <XAxis />
  <ChartTooltip />
</LineChart>
```

On time-series charts the fit uses the date as x. On `BarChart` it uses the category index, so the line runs through bar centers (and along the value axis when `orientation="horizontal"`). Non-numeric values are skipped. The line fades in with the chart reveal (after bars land) and tweens to the new fit when data changes.
