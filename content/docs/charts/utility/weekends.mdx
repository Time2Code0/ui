## Usage

`Weekends` draws a band over every weekend span on a date x axis. Place it as a child of `LineChart`, `AreaChart`, `ComposedChart`, `CandlestickChart`, or `BarChart` (with date rows). It renders in the underlay layer — above grid and background, behind series.

```tsx
import { LineChart } from "@/components/charts/line-chart"
import { Line } from "@/components/charts/line"
import { Grid } from "@/components/charts/grid"
import { Weekends } from "@/components/charts/weekends"
import { ChartTooltip } from "@/components/charts/tooltip/chart-tooltip"
import { XAxis } from "@/components/charts/x-axis"

;<LineChart data={data}>
  <Grid horizontal />
  <Weekends />
  <Line dataKey="completed" />
  <XAxis />
  <ChartTooltip />
</LineChart>
```

- **Time scales** (line, area, composed, candlestick) — only spans inside the visible x-domain are drawn, so brush zoom and long ranges stay cheap. When one day is narrower than `minDayWidth` pixels (e.g. multi-year ranges), nothing renders.
- **Band scales** (`BarChart`) — consecutive weekend columns merge into one band that covers the full column slots. Dates are read from the first field holding a `Date` or a `"YYYY-MM-DD"` string; pass `dateKey` to pick one. Horizontal bar charts shade rows instead of columns.
- **Locales** — set `weekendDays` with `Date#getDay()` numbers (0 = Sunday … 6 = Saturday), e.g. `[5, 6]` for Friday–Saturday weekends.
- **Time zones** — day boundaries use local time. Pass `utc` when your dates are anchored to UTC (e.g. ISO strings ending in `Z`).
- **Alignment** — by default bands run midnight to midnight. On a `ComposedChart` with `SeriesBar` columns at midnight, `align="auto"` shifts bands half a day so each column sits inside its day.

The date math is exported as `computeWeekendRanges(start, end, options)` (time domains) and `computeWeekendIndexRuns(dates, options)` (row runs) if you need the spans elsewhere — for example to skip weekends in a tooltip.
