## Usage

```tsx
import { useInterval } from "@/hooks/use-interval"

function Counter() {
  const [count, setCount] = useState(0)

  useInterval(() => setCount(count + 1), 1000)

  return <span>{count}</span>
}
```

The latest callback is stored in a ref, so reading `count` directly works without restarting the interval on every render.

### Pausing

Pass `null` as the delay to stop the interval. Passing a number again starts a fresh interval.

```tsx
const [running, setRunning] = useState(true)

useInterval(tick, running ? 1000 : null)
```

## API Reference

```tsx
function useInterval(callback: () => void, delay: number | null): void
```

| Parameter  | Type             | Description                                          |
| ---------- | ---------------- | ---------------------------------------------------- |
| `callback` | `() => void`     | Called on every tick                                 |
| `delay`    | `number \| null` | Time between ticks in milliseconds. `null` pauses it |
