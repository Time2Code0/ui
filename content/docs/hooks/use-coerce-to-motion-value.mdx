Accepts either a plain value or a Motion value and always returns a Motion value. Use it in components that should accept both static and animated props.

## Installation

<InstallationTabs name="use-coerce-to-motion-value" />

## Usage

```tsx
import type { MotionValue } from "motion/react"
import { motion, useTransform } from "motion/react"

import { useCoerceToMotionValue } from "@/hooks/use-coerce-to-motion-value"

function ProgressBar({ value }: { value: number | MotionValue<number> }) {
  const progress = useCoerceToMotionValue(value)
  const scaleX = useTransform(progress, [0, 100], [0, 1])

  return <motion.div className="origin-left" style={{ scaleX }} />
}

<ProgressBar value={60} />
<ProgressBar value={animatedValue} />
```

A Motion value is returned as is. A plain value is wrapped in a new Motion value that is kept in sync when the prop changes.

## API Reference

```tsx
function useCoerceToMotionValue<T>(value: T | MotionValue<T>): MotionValue<T>
```

| Parameter | Type                  | Description                    |
| --------- | --------------------- | ------------------------------ |
| `value`   | `T \| MotionValue<T>` | A plain value or Motion value  |
