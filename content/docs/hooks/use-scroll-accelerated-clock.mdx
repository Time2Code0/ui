A [useClock](/docs/hooks/use-clock) whose speed follows the scroll. Scrolling down speeds the clock up, and scrolling up runs it backwards. Once scrolling stops it settles back to normal speed in the last scroll direction.

## Installation

<InstallationTabs name="use-scroll-accelerated-clock" />

## Usage

The hook reads the scroll velocity from the [Scroll](/docs/marketing/scroll) context, so it must be rendered inside a `WindowScrollProvider` or a `ScrollContainer`.

```tsx
import { motion, useTransform } from "motion/react"

import { useScrollAcceleratedClock } from "@/hooks/use-scroll-accelerated-clock"
import { WindowScrollProvider } from "@/components/marketing/scroll"

function Spinner() {
  const clock = useScrollAcceleratedClock()
  const rotate = useTransform(clock.value, (value) => value * 0.09)

  return <motion.div style={{ rotate }} />
}

export function Page() {
  return (
    <WindowScrollProvider>
      <Spinner />
    </WindowScrollProvider>
  )
}
```

The [Ticker](/docs/marketing/ticker) component is a typical consumer: pass `clock.value` to it to make a marquee react to scrolling.

## API Reference

```tsx
function useScrollAcceleratedClock(acceleration?: number): Clock
```

| Parameter      | Type     | Default | Description                                      |
| -------------- | -------- | ------- | ------------------------------------------------ |
| `acceleration` | `number` | `5`     | How strongly the scroll velocity affects the rate |

Returns the same `{ value, setRate }` object as [useClock](/docs/hooks/use-clock). The rate is overwritten on every scroll velocity change, so calling `setRate` yourself only lasts until the next scroll.
