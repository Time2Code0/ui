## Usage

```tsx
import { useResizeObserver } from "@/hooks/use-resize-observer"

function Size() {
  const ref = useRef<HTMLDivElement>(null)
  const entry = useResizeObserver(ref)

  return (
    <div ref={ref}>
      {entry?.contentRect.width} × {entry?.contentRect.height}
    </div>
  )
}
```

The entry is `undefined` until the first measurement. Besides `contentRect` it includes `borderBoxSize` and `contentBoxSize` if you need the size including padding and border.

The element is read once when the hook mounts. If the ref is attached to an element that renders conditionally, render the hook inside that element's component so the element exists on mount.

## API Reference

```tsx
function useResizeObserver(
  elementRef: React.RefObject<Element | null> | null
): ResizeObserverEntry | undefined
```

| Parameter    | Type                                      | Description         |
| ------------ | ----------------------------------------- | ------------------- |
| `elementRef` | `React.RefObject<Element \| null> \| null` | Element to observe  |

Returns the latest [`ResizeObserverEntry`](https://developer.mozilla.org/docs/Web/API/ResizeObserverEntry), or `undefined` before the first measurement.
