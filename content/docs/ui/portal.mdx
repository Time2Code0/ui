## Usage

```tsx
import { Portal } from "@/components/ui/portal"
```

```tsx
<Portal className="fixed right-4 bottom-4">Floating content</Portal>
```

`Portal` wraps its children in a `div` and moves it into `document.body` with React's `createPortal`. Use it for content that has to escape a parent's `overflow` or stacking context, such as floating panels or full-screen overlays.

Nothing is rendered on the server or during the first client render. The portal mounts after hydration, once `document` is available, so it never causes a hydration mismatch.

### Custom container

Pass `container` to render somewhere other than `document.body`. Store the target element in state so the portal re-renders once it exists.

```tsx
const [container, setContainer] = useState<HTMLDivElement | null>(null)

return (
  <>
    <Portal container={container}>Moved content</Portal>
    <div ref={setContainer} />
  </>
)
```

## API Reference

### Portal

Accepts every `div` prop. They're applied to the wrapper element that gets moved.

| Prop        | Type                                 | Default         | Description                 |
| ----------- | ------------------------------------ | --------------- | --------------------------- |
| `container` | `Element \| DocumentFragment \| null` | `document.body` | Element to render into      |
