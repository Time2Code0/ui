## Usage

```tsx
import { Kbd, KbdGroup } from "@/components/ui/kbd"
```

Single key:

```tsx
<Kbd>K</Kbd>
```

Multiple keys (key combination):

```tsx
<KbdGroup>
  <Kbd>⌘</Kbd>
  <Kbd>K</Kbd>
</KbdGroup>
```

## API Reference

### Kbd

Displays a single keyboard key.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

### KbdGroup

Groups multiple keyboard keys for key combinations.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |
