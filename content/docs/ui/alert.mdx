## API Reference

This is a custom component, not a Base UI wrapper.

### Alert

Root container for the alert.

| Prop      | Type                                                        | Default     | Description                                      |
| --------- | ----------------------------------------------------------- | ----------- | ------------------------------------------------ |
| `variant` | `"default" \| "error" \| "info" \| "success" \| "warning"` | `"default"` | Controls the alert styling and color scheme      |

### AlertTitle

Title text for the alert. Renders as a styled `div`.

### AlertDescription

Description text for the alert. Renders as a styled `div` with muted foreground color.

### AlertAction

Container for action buttons. Automatically positions to the right on larger screens.

### AlertFrame

Framed container that wraps an `Alert` and adds a footer below it. Shows an animated striped ribbon on hover.

The frame doesn't pass its variant down, so give the inner `Alert` the same `variant` to keep both colors in sync.

```tsx
<AlertFrame variant="info">
  <Alert variant="info">...</Alert>
  <AlertFrameFooter>...</AlertFrameFooter>
</AlertFrame>
```

| Prop      | Type                                                         | Default     | Description                     |
| --------- | ------------------------------------------------------------ | ----------- | ------------------------------- |
| `variant` | `"default" \| "info" \| "success" \| "warning" \| "error"` | `"default"` | Controls the frame color        |

### AlertFrameFooter

Footer row inside `AlertFrame`. Lays out an optional leading icon, an `AlertFrameDescription` and an `AlertFrameAction`.

### AlertFrameDescription

Muted text inside `AlertFrameFooter`. Tinted to match the frame variant.

### AlertFrameAction

Container for action buttons, aligned to the end of the footer.
