## Link

Links should stay links. To make one look like a button, apply `buttonVariants()` to the link directly instead of rendering it through `Button`. It accepts the same `variant`, `shape` and `size` options.

```tsx
import { buttonVariants } from "@/components/ui/button"
import { Link } from "@/components/ui/link"

export function LinkAsButton() {
  return (
    <Link className={buttonVariants({ variant: "outline" })} href="/login">
      Login
    </Link>
  )
}
```

## API Reference

### Button

A button component with variant, shape, size, and loading states. Styled wrapper for `Button` from Base UI.

| Prop      | Type                                                                                                                    | Default     | Description                                                       |
| --------- | ----------------------------------------------------------------------------------------------------------------------- | ----------- | ----------------------------------------------------------------- |
| `variant` | `"default" \| "destructive" \| "ghost" \| "link" \| "animated-link" \| "outline" \| "secondary" \| "unstyled"` | `"default"` | Controls the button styling                                       |
| `size`    | `"default" \| "icon" \| "icon-lg" \| "icon-sm" \| "icon-xl" \| "icon-xs" \| "lg" \| "sm" \| "xl" \| "xs"`           | `"default"` | Controls the button size                                          |
| `shape`   | `"default" \| "full" \| "none"`                                                                                         | `"default"` | Controls the border radius                                        |
| `loading` | `boolean`                                                                                                               | `false`     | Shows a spinner and disables the button while loading             |
| `render`  | `React.ReactElement`                                                                                                    | -           | Render as a different element (e.g., Link)                        |

When `loading` is `true`, the component:

- Renders a spinner (`data-slot="button-loading-indicator"`)
- Adds `data-loading` on the button root
- Disables the button while keeping it focusable (`focusableWhenDisabled`)
- Preserves button width by hiding content visually instead of unmounting it
