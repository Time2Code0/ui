## Usage

```tsx
import { Label } from "@/components/ui/label"
import { Radio, RadioGroup } from "@/components/ui/radio-group"
```

```tsx
<RadioGroup defaultValue="next">
  <Label>
    <Radio value="next" /> Next.js
  </Label>
  <Label>
    <Radio value="vite" /> Vite
  </Label>
  <Label>
    <Radio value="astro" /> Astro
  </Label>
</RadioGroup>
```

## API Reference

### RadioGroup

Root component. Styled wrapper for `RadioGroup.Root` from Base UI with flex column layout.

### Radio

Individual radio button. Styled wrapper for `Radio.Root` from Base UI with built-in indicator.

## Examples

For accessible labelling and validation, prefer using the `Field` component to wrap radio buttons. See the related example: [Radio Group field](/docs/ui/field#radio-group-field).

For tabs-style mutually exclusive choices, see the [Segmented Control](/docs/ui/segmented-control) pattern.
