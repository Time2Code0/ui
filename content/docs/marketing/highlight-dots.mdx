## Usage

```tsx
import { HighlightDots } from "@/components/marketing/highlight-dots"
```

```tsx
<section className="relative h-96">
  <HighlightDots containerClassName="flex items-center justify-center">
    <h2>Highlight Dots</h2>
  </HighlightDots>
</section>
```

`HighlightDots` fills its nearest positioned ancestor with the [Dot pattern](/docs/marketing/pattern), so the parent needs `relative` positioning and a size. The highlight fades in while the cursor is inside and follows it through [useMousePosition](/docs/hooks/use-mouse-position).

Use `containerClassName` to lay out the content within the full area, and `className` to style the wrapper around the children.

## API Reference

Accepts every `div` prop.

| Prop                 | Type     | Default | Description                               |
| -------------------- | -------- | ------- | ----------------------------------------- |
| `containerClassName` | `string` |         | Class names for the full-size root        |
| `className`          | `string` |         | Class names for the wrapper of `children` |
