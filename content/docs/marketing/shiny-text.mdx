@theme inline {
  --animate-shiny-text: shiny-text var(--duration) infinite;
}

@keyframes shiny-text {
  from {
    background-position: calc(-100% - var(--shimmer-width)) 0;
  }
  to {
    background-position: calc(100% + var(--shimmer-width)) 0;
  }
}

## Usage

```tsx
import { ShinyText } from "@/components/marketing/shiny-text"
```

```tsx
<ShinyText>✨ Introducing our new design system</ShinyText>
```

By default the shimmer repeats continuously. Set `onlyOnHover` to play it once each time the text is hovered.

## API Reference

Accepts every `span` prop.

| Prop           | Type      | Default | Description                         |
| -------------- | --------- | ------- | ----------------------------------- |
| `shimmerWidth` | `number`  | `100`   | Width of the light band in pixels   |
| `duration`     | `number`  | `5`     | Seconds per sweep                   |
| `onlyOnHover`  | `boolean` | `false` | Only plays the shimmer on hover     |
