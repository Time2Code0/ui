Fills text with a gradient from the `primary` to the `secondary` theme color, optionally animated.

## Installation

<InstallationTabs name="gradient-text" />

## Usage

```tsx
import { GradientText } from "@/components/marketing/gradient-text"
```

```tsx
<h1>
  Ship <GradientText>faster</GradientText>
</h1>
```

`GradientText` renders an inline `span`, so it inherits the font size and weight of its surroundings. Set `animate` to let the gradient flow continuously across the text.

### Custom colors

Override the gradient stops with Tailwind classes. With `animate`, also set the `via-*` color.

```tsx
<GradientText className="from-success to-info">Custom</GradientText>
```

## API Reference

Accepts every `span` prop.

| Prop      | Type      | Default | Description                    |
| --------- | --------- | ------- | ------------------------------ |
| `animate` | `boolean` | `false` | Animates the gradient          |
