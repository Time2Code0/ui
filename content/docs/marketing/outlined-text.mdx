## Usage

```tsx
import { OutlinedText } from "@/components/marketing/outlined-text"
```

```tsx
<h1 className="font-bold text-6xl">
  <OutlinedText>Outlined</OutlinedText>
</h1>
```

Change the stroke color with an arbitrary `-webkit-text-stroke-color` class:

```tsx
<OutlinedText className="[-webkit-text-stroke-color:var(--color-primary)]" strokeWidth={2}>
  Outlined
</OutlinedText>
```

## API Reference

Accepts every `span` prop.

| Prop          | Type     | Default | Description                  |
| ------------- | -------- | ------- | ---------------------------- |
| `strokeWidth` | `number` | `1`     | Width of the outline in pixels |
