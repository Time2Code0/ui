Scrolls its children in an endless loop, horizontally or vertically. Use it for logo walls, testimonials and tickers.

## Installation

<InstallationTabs name="marquee" />

## Usage

```tsx
import { Marquee } from "@/components/marketing/marquee"
```

```tsx
<Marquee pauseOnHover>
  {logos.map((logo) => (
    <Logo key={logo.name} {...logo} />
  ))}
</Marquee>
```

The children are rendered `repeat` times side by side and shifted with a CSS animation, so the loop has no visible seam. Increase `repeat` when the content is narrower than the container.

### Speed and spacing

The duration of one loop and the gap between items are CSS variables. Override them with Tailwind classes:

```tsx
<Marquee className="[--duration:40s] [--gap:2rem]">...</Marquee>
```

### Fading the edges

Combine the marquee with a [Mask](/docs/marketing/mask) to fade the items in and out at the edges.

## API Reference

| Prop           | Type              | Default | Description                              |
| -------------- | ----------------- | ------- | ---------------------------------------- |
| `children`     | `React.ReactNode` |         | Items to scroll                          |
| `vertical`     | `boolean`         | `false` | Scrolls vertically                       |
| `reverse`      | `boolean`         | `false` | Reverses the direction                   |
| `pauseOnHover` | `boolean`         | `false` | Pauses while hovered                     |
| `repeat`       | `number`          | `2`     | How many copies of the children to render |
| `className`    | `string`          |         | Class names for the root element         |
