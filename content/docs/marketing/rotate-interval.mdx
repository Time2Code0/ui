## Usage

```tsx
import { RotateInterval } from "@/components/marketing/rotate-interval"
```

```tsx
<h1 className="flex gap-2">
  Build
  <RotateInterval interval={2000} items={["faster", "better", "together"]} />
</h1>
```

Items can be any React node. After the last item it starts over with the first. The container clips the items while they animate; style it with `containerClassName`, and the animated item with `className`.

## API Reference

Accepts every prop of `motion.div`, applied to the animated item.

| Prop                 | Type                | Description                          |
| -------------------- | ------------------- | ------------------------------------ |
| `items`              | `React.ReactNode[]` | Items to cycle through               |
| `interval`           | `number`            | Time per item in milliseconds        |
| `containerClassName` | `string`            | Class names for the clipping container |
