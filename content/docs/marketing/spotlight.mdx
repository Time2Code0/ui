## Usage

```tsx
import { Spotlight } from "@/components/marketing/spotlight"
```

```tsx
<section className="relative isolate overflow-hidden">
  <Spotlight />
  <Spotlight orientation="right" />
  <h1>Spotlight</h1>
</section>
```

The spotlight is positioned behind the content of its nearest positioned ancestor (`-z-10`), so give that ancestor `isolate` to keep the light above its own background. It fades in on mount.

`color` takes the red, green and blue channels as a comma separated string:

```tsx
<Spotlight color="120, 160, 255" />
```

## API Reference

Accepts every prop of `motion.span`, applied to the light.

| Prop                 | Type                  | Default           | Description                          |
| -------------------- | --------------------- | ----------------- | ------------------------------------ |
| `orientation`        | `"left" \| "right"`   | `"left"`          | Corner the light comes from          |
| `color`              | `string`              | `"209, 205, 125"` | RGB channels of the light            |
| `containerClassName` | `string`              |                   | Class names for the wrapper          |
