## Usage

```tsx
import { ImageComparison } from "@/components/marketing/image-comparison"
```

```tsx
<ImageComparison
  after="/after.png"
  before="/before.png"
  className="aspect-video overflow-hidden rounded-xl"
/>
```

The `before` image fills the component and the `after` image is laid on top of it. The divider is driven by an invisible range input that covers the whole component, so it works with pointer, touch and keyboard. Both images use `object-cover`, so set the size and aspect ratio with `className`.

## API Reference

| Prop        | Type     | Default | Description                         |
| ----------- | -------- | ------- | ----------------------------------- |
| `before`    | `string` |         | URL of the image on the left        |
| `after`     | `string` |         | URL of the image on the right       |
| `className` | `string` |         | Class names for the root element    |
