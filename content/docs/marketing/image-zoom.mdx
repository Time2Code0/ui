Click an image to zoom it smoothly from its position on the page to fill the viewport. Click again, press Escape or scroll to return.

<InstallationTabs name="image-zoom" />

## Usage

```tsx
import { ImageZoom } from "@/components/marketing/image-zoom"
```

```tsx
<ImageZoom className="overflow-hidden rounded-xl">
  <img alt="Screenshot" height={630} src="/screenshot.png" width={1200} />
</ImageZoom>
```

`ImageZoom` wraps its children in a button that opens the zoomed view. The zoomed copy is rendered in a [Portal](/docs/ui/portal) above a dimmed backdrop and scaled to fit the viewport, keeping `gutter` pixels of space around it. Any content works as children, including `next/image`.

The zoomed view closes on click, on scroll, and with the Escape, Arrow Up and Arrow Down keys.

### Controlling the state

`onOpenChange` is called whenever the image opens or closes.

```tsx
<ImageZoom onOpenChange={(open) => console.log(open)}>...</ImageZoom>
```

## API Reference

Accepts every `button` prop.

| Prop           | Type                      | Default | Description                                     |
| -------------- | ------------------------- | ------- | ----------------------------------------------- |
| `gutter`       | `number`                  | `24`    | Space between the zoomed image and the viewport edge in pixels |
| `onOpenChange` | `(open: boolean) => void` |         | Called when the zoomed view opens or closes     |
