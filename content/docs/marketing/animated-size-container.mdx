A container that animates its width or height whenever its content changes size. Use it to smooth out tab switches, expanding sections or content that loads in.

## Usage

```tsx
import { AnimatedSizeContainer } from "@/components/marketing/animated-size-container"
```

```tsx
<AnimatedSizeContainer height>
  {expanded ? <LongContent /> : <ShortContent />}
</AnimatedSizeContainer>
```

The content is measured with [useResizeObserver](/docs/hooks/use-resize-observer) and the outer element animates to the measured size. Set `width`, `height` or both to choose which dimensions animate. The outer element hides overflow so content never spills out mid-animation.

### Custom transition

Pass a Motion `transition` to change the animation. The default is a spring with a duration of 0.3 seconds.

```tsx
<AnimatedSizeContainer height transition={{ duration: 0.5, ease: "easeInOut" }}>
  ...
</AnimatedSizeContainer>
```

## API Reference

Accepts every prop of `motion.div` except `animate`.

| Prop         | Type         | Default                              | Description              |
| ------------ | ------------ | ------------------------------------ | ------------------------ |
| `width`      | `boolean`    | `false`                              | Animates width changes   |
| `height`     | `boolean`    | `false`                              | Animates height changes  |
| `transition` | `Transition` | `{ type: "spring", duration: 0.3 }`  | Motion transition        |
