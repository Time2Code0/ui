[Gradient Text](/docs/marketing/gradient-text) with an animated gradient that sparkles with little stars while hovered. Use it to emphasize a single word in a headline.

## Installation

<InstallationTabs name="magic-text" />

## Usage

```tsx
import { MagicText } from "@/components/marketing/magic-text"
```

```tsx
<h1>
  Turn ideas into <MagicText>magic</MagicText>
</h1>
```

`MagicText` renders inline. While the cursor is over it, three stars keep appearing at random positions around the text, scale in, spin and disappear. They use the `primary` color.

## API Reference

| Prop       | Type              | Description        |
| ---------- | ----------------- | ------------------ |
| `children` | `React.ReactNode` | Text to highlight  |
