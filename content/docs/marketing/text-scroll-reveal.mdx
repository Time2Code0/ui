## Usage

```tsx
import { TextScrollReveal } from "@/components/marketing/text-scroll-reveal"
```

```tsx
<TextScrollReveal
  className="h-[200vh] text-4xl"
  text="Scroll down and watch each word light up as you read along."
/>
```

The text is sticky inside the component, so the component's height decides how long the reveal takes: a taller component means more scrolling per word. Give it a height well above the viewport, such as `h-[200vh]`. Progress follows the scroll of the page.

## API Reference

| Prop        | Type     | Description                                |
| ----------- | -------- | ------------------------------------------ |
| `text`      | `string` | Text to reveal, split into words by spaces |
| `className` | `string` | Class names for the root element           |
