A pill-shaped [Button](/docs/ui/button) with a rotating light around its border and a field of stars inside. Made for primary calls to action on dark backgrounds.

### Add the following to your CSS file: [step]

```css
@theme inline {
  --animate-magic-button-border-turn: magic-button-border-turn var(--duration) linear infinite;
  --animate-magic-button-border-turn-with-translate: magic-button-border-turn-with-translate var(--duration) linear infinite;
}

@keyframes magic-button-border-turn {
  0% {
    transform: rotate(0);
  }
  100% {
    transform: rotate(360deg);
  }
}

@keyframes magic-button-border-turn-with-translate {
  0% {
    transform: translate(-50%, -50%) rotate(0);
  }
  100% {
    transform: translate(-50%, -50%) rotate(360deg);
  }
}
```

## Usage

```tsx
import { MagicButton } from "@/components/marketing/magic-button"
```

```tsx
<MagicButton>Get started</MagicButton>
```

The light and stars are white, so the effect only shows on dark surfaces. `duration` sets how long one rotation of the light takes. `className` styles the button itself and `containerClassName` the wrapper that holds the effects.

## API Reference

Accepts every `button` prop.

| Prop                 | Type     | Default | Description                         |
| -------------------- | -------- | ------- | ----------------------------------- |
| `duration`           | `number` | `2`     | Seconds per rotation of the light   |
| `containerClassName` | `string` |         | Class names for the wrapper         |
