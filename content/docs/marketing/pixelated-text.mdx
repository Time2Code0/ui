## Usage

```tsx
import { PixelatedText } from "@/components/marketing/pixelated-text"
```

```tsx
<h1 className="font-black text-7xl">
  <PixelatedText>PIXEL</PixelatedText>
</h1>
```

The dots use the foreground color and are clipped to the shape of the text, so heavy font weights give the best result. `pixelSize` sets the spacing between dots.

## API Reference

Accepts every `span` prop.

| Prop        | Type     | Default | Description                    |
| ----------- | -------- | ------- | ------------------------------ |
| `pixelSize` | `number` | `5`     | Distance between dots in pixels |
