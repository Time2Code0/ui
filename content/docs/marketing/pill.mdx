## Usage

```tsx
import { Pill } from "@/components/marketing/pill"
```

```tsx
<Pill>Introducing our new design system</Pill>
```

Set `animate` to let the gradient flow around the border. `className` styles the inner label and `containerClassName` the outer element that draws the border.

To make the whole pill a link, wrap it:

```tsx
<a href="/changelog">
  <Pill>See what's new →</Pill>
</a>
```

## API Reference

| Prop                 | Type              | Default | Description                         |
| -------------------- | ----------------- | ------- | ----------------------------------- |
| `children`           | `React.ReactNode` |         | Content of the pill                 |
| `animate`            | `boolean`         | `false` | Animates the gradient border        |
| `className`          | `string`          |         | Class names for the inner label     |
| `containerClassName` | `string`          |         | Class names for the outer element   |
