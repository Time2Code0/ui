## Usage

```tsx
import { HoverRotateText } from "@/components/marketing/hover-rotate-text"
```

```tsx
<a href="/pricing">
  <HoverRotateText text="Pricing" />
</a>
```

The effect is pure CSS and triggers when the cursor is over the component.

### Splitting

`splitBy` decides how the text is divided:

- `char`: each character moves on its own.
- `word`: each word moves on its own.
- `none`: the whole text moves at once.

Each part starts `delay` milliseconds after the previous one, which creates the wave.

## API Reference

Accepts every `div` prop except `children`.

| Prop      | Type                          | Default  | Description                              |
| --------- | ----------------------------- | -------- | ---------------------------------------- |
| `text`    | `string`                      |          | Text to display                          |
| `splitBy` | `"char" \| "word" \| "none"`  | `"char"` | How the text is split into moving parts  |
| `delay`   | `number`                      | `20`     | Delay between parts in milliseconds      |
