Skills give AI coding assistants structured knowledge about **time2code/ui**: component APIs, composition patterns, styling conventions, migration rules and common pitfalls. With the skills installed, your assistant uses the components correctly instead of guessing from shadcn/ui or Radix UI habits.

For example, you can ask your assistant to:

- _"Add a settings dialog with a form and save and cancel buttons."_
- _"Add a select with grouped options and a search field."_
- _"Migrate this shadcn/ui dropdown menu to time2code/ui."_
- _"Show a toast when the form fails to submit."_
- _"Build a revenue dashboard with a stacked bar chart and KPI cards."_

## Install

```bash
npx skills add time2code0/ui
```

This installs the time2code/ui skills into your project. Select all three when prompted. Once installed, your assistant loads them automatically when it works with time2code/ui.

To install a single skill, pass its name:

```bash
npx skills add time2code0/ui --skill time2code-ui
```

Learn more about the skills ecosystem at [skills.sh](https://skills.sh).

## Available Skills

| Skill | Use it for |
| --- | --- |
| `time2code-ui` | The primary skill: installation, the CLI, styling, color tokens and the UI components. |
| `time2code-charts` | Charts, sparklines and chart add-ons such as tooltips, legends, markers and reference areas. |
| `time2code-particles` | An index of every [particle](/particles) for UI components, charts, marketing components and hooks. |

The charts and particles skills build on `time2code-ui` and link to it, so install them together.

## What's Included

The skills cover the full time2code/ui surface:

### Component Knowledge

Reference guides for every UI component: imports, minimal examples, composition rules and common pitfalls. The assistant knows when to use Dialog, Sheet or Drawer, how to compose triggers with the `render` prop and how to structure forms with Field.

### Styling Conventions

The [color tokens](/docs/styling#color-tokens) and how they map from shadcn/ui, the default border color, dark mode, [Hugeicons](https://hugeicons.com) through the `Icon` component, and the root layout that popups and toasts need.

### Migration Patterns

Rules for moving from shadcn/ui and Radix UI to Base UI: `asChild` to `render`, `*Content` to `*Popup`, Dropdown Menu to Menu, the `items`-first Select, Toggle Group `type` to `multiple`, scalar Slider values and `input-otp` to `OTPField`.

### Charts

How to install, compose, theme and animate the charts: the import path of every export, the order of grid, series, axes, overlays and tooltip, the `--color-chart-*` palette, and loading and empty states.

### CLI and Registry

How to add components with the `time2code` CLI or with the shadcn CLI and the `@time2code` namespace, how to start a new project with `time2code create`, and how to connect the MCP server.

### Particle Examples

A generated index of every particle with a short description and the URL of its registry JSON, so the assistant can base its code on complete, realistic examples instead of minimal stubs.

## How It Works

1. **Skill activation:** Your assistant detects the installed skills in your project.
2. **Progressive loading:** Each skill's root `SKILL.md` holds the core rules and an index. Detailed component guides, rule references and particle indexes load only when a task needs them.
3. **Pattern enforcement:** The assistant follows the composition rules, such as the `render` prop for triggers, the `DialogHeader`, `DialogPanel` and `DialogFooter` structure, `variant="ghost"` for cancel buttons and links styled with `buttonVariants()`.
4. **Example-driven output:** Before writing code, the assistant checks the particles for a matching pattern.

## Supported Agents

The skills follow the [Agent Skills](https://agentskills.io) format, so they work with any assistant that supports it, including Claude Code, Cursor, Codex, Cline, Windsurf, GitHub Copilot and many more.

## Other AI Tools

The skills work well together with these tools:

- **MCP server:** Run `npx time2code mcp init` to connect the `time2code` MCP server to Claude Code, Cursor, VS Code, OpenCode or Codex. It lets your assistant list, search and view components, get usage examples and get the add command.
- **llms.txt:** Point your assistant at [llms.txt](/llms.txt) for a map of the documentation, or [llms-full.txt](/llms-full.txt) for all of it.
- **Markdown pages:** Use the **Copy Markdown** button on any page to paste its content into a chat.
