**time2code/ui** is a collection of accessible, composable React components for production apps and the marketing sites around them. The components are built on [Base UI](https://base-ui.com/) and styled with [Tailwind CSS v4](https://tailwindcss.com/). You copy them into your project and own the code.

## How It Works

time2code/ui follows the copy-and-own approach of **shadcn/ui**. Instead of installing a package, you add the source code of each component to your project:

- **No abstractions:** You control how every component looks and behaves.
- **Customize anything:** To change a component, edit its file.
- **Learn from the source:** See how each component is built and adapt it to your needs.

The components are published as a [shadcn registry](https://ui.shadcn.com/docs/registry), so you can add them with the `time2code` CLI or the shadcn CLI. See [Get Started](/docs/get-started).

## Built on Base UI

Base UI provides unstyled primitives that handle the hard parts of a component: accessibility, keyboard navigation and focus management. time2code/ui adds a design system on top of them:

- **Color tokens** for surfaces, text and status colors, with a dark mode for each. See [Styling](/docs/styling).
- **Variants and sizes** for common use cases.
- **Defaults** tuned for dense application interfaces.

The component APIs stay close to shadcn/ui, but they use Base UI patterns, such as the `render` prop instead of `asChild`. A migration guide for projects built on shadcn/ui or Radix UI is planned.

## What's Included

The library covers both sides of a product, the app and the site that sells it:

- **[UI Components](/docs/ui)**: Accessible primitives like Button, Dialog, Menu and Select.
- **[Particles](/particles)**: Ready-made examples that combine components into patterns, such as forms, tables and date pickers.
- **[Blocks](/blocks)**: Complete pages, such as a login page, to start from.
- **[Charts](/docs/charts)**: Composable charts that share one color palette.
- **[Marketing Components](/docs/marketin/animate)**: Animated text, backgrounds and effects for landing pages.
- **[Hooks](/docs/hooks/use-active-anchor)**: React hooks the components use, also available on their own.

Start with a UI component when you need a building block, and with a particle or block when you need a working pattern you can adapt.

## Built for Humans and AI

The components are written to be clear, readable and predictable, so that language models can understand and modify them as well as you can. Every page is available as Markdown, the [llms.txt](/llms.txt) file maps the documentation, and the `time2code` CLI includes an MCP server for AI agents. See [Working With AI](/docs/get-started#working-with-ai) for details.
