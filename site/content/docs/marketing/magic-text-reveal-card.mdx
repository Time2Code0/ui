A card with faded text that reveals a different text wherever the cursor has passed, like wiping a foggy window.

## Installation

<InstallationTabs name="magic-text-reveal-card" />

## Usage

```tsx
import { MagicTextRevealCard } from "@/components/marketing/magic-text-reveal-card"
```

```tsx
<MagicTextRevealCard revealText="Here's the secret" text="Hover over me">
  <p>Move your cursor across the card</p>
</MagicTextRevealCard>
```

`text` is shown faded with drifting sparkles. As the cursor moves to the right, `revealText` is uncovered up to the cursor position, with a light line marking the edge. When the cursor leaves, the reveal slides back. Children render above the text, for example a title or hint.

The effect follows the mouse, so on touch devices only `text` is visible.

## API Reference

| Prop         | Type              | Description                         |
| ------------ | ----------------- | ----------------------------------- |
| `text`       | `string`          | Text shown by default               |
| `revealText` | `string`          | Text uncovered by the cursor        |
| `children`   | `React.ReactNode` | Content above the text              |
| `className`  | `string`          | Class names for the card            |
