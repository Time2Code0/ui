[Cards](/docs/ui/card) that stick to the top of the viewport while scrolling and stack on top of each other. Cards further down the stack shrink slightly, which creates depth.

## Installation

<InstallationTabs name="sticky-stacked-card" />

## Usage

```tsx
import { Root, StackedCard } from "@/components/marketing/sticky-stacked-card"
```

```tsx
<Root>
  <StackedCard index={1}>Install</StackedCard>
  <StackedCard index={2}>Customize</StackedCard>
  <StackedCard index={3}>Ship</StackedCard>
</Root>
```

Number the cards from `1` in the order they appear. Each card sticks a little lower than the previous one, and all but the last scale down as the page scrolls past the stack. The effect follows the scroll of the page, so the stack needs enough content below it to scroll through.

## API Reference

### Root

Wraps the cards and tracks their scroll progress. Accepts every `div` prop.

### StackedCard

| Prop        | Type              | Description                          |
| ----------- | ----------------- | ------------------------------------ |
| `index`     | `number`          | Position in the stack, starting at `1` |
| `className` | `string`          | Class names for the card             |
| `children`  | `React.ReactNode` | Card content                         |
