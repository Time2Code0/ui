A [Card](/docs/ui/card) with a light reflection that sweeps across it when the cursor enters.

## Installation

<InstallationTabs name="highlight-card" />

## Usage

```tsx
import { HighlightCard } from "@/components/marketing/highlight-card"
```

```tsx
<HighlightCard angle={20}>
  <h3>Analytics</h3>
  <p>Understand how your product is used.</p>
</HighlightCard>
```

Children render inside a `CardPanel`. The reflection plays once per hover and resets when the cursor leaves. `angle` tilts the reflection.

The reflection is a translucent white gradient, so it shows best on dark cards.

## API Reference

| Prop        | Type              | Default | Description                         |
| ----------- | ----------------- | ------- | ----------------------------------- |
| `angle`     | `number`          | `0`     | Rotation of the reflection in degrees |
| `className` | `string`          |         | Class names for the card            |
| `children`  | `React.ReactNode` |         | Card content                        |
