## Usage

`ChartMarkers` pins an icon badge above the plot at each marker's `date`, with a dashed guide line down through the chart. Place it as a child of a time-series chart (`LineChart`, `AreaChart`, `ComposedChart`). Markers render after the interaction overlay, so they stay hoverable and clickable on top of the crosshair.

```tsx
import {
  ChartMarkers,
  MarkerTooltipContent,
  useActiveMarkers,
} from "@/components/charts/chart-markers/chart-markers"
import { ChartTooltip } from "@/components/charts/chart-tooltip/chart-tooltip"
import { Grid } from "@/components/charts/chart-grid/grid"
import { Line } from "@/components/charts/line-chart/line"
import { LineChart } from "@/components/charts/line-chart/line-chart"
import type {
  ChartMarker,
} from "@/components/charts/chart-markers/marker-group"
import { XAxis } from "@/components/charts/chart-axis/x-axis"

const markers: ChartMarker[] = [
  {
    date: new Date(2024, 0, 4),
    icon: "🚀",
    title: "v2.0 Launch",
    description: "Major release with new features",
    href: "https://example.com/changelog",
    target: "_blank",
  },
  { date: new Date(2024, 0, 9), icon: "📣", title: "Marketing Push" },
  { date: new Date(2024, 0, 9), icon: "🐛", title: "Bug Fix" }, // same day → stacks
]

// Shows the markers for the hovered date inside the chart tooltip
function MarkerContent({ markers }: { markers: ChartMarker[] }) {
  const activeMarkers = useActiveMarkers(markers)
  if (activeMarkers.length === 0) return null
  return <MarkerTooltipContent markers={activeMarkers} />
}

;<LineChart data={data}>
  <Grid horizontal />
  <Line dataKey="value" />
  <ChartMarkers items={markers} />
  <XAxis />
  <ChartTooltip>
    <MarkerContent markers={markers} />
  </ChartTooltip>
</LineChart>
```

Markers that share a calendar day are grouped into one badge with a count. Hovering the badge fans the group out in a radial arc; each fanned badge is clickable when the marker has `onClick` or `href`. When the crosshair lands on a marker's date, `useActiveMarkers` returns those markers so `MarkerTooltipContent` can list them under the tooltip rows.

## Marker item

```ts
interface ChartMarker {
  date: Date // Matched to data points by calendar day
  icon: React.ReactNode // Emoji, SVG, or image inside the badge
  title: string // Tooltip title (also the React key in the fan)
  description?: string // Secondary tooltip line
  content?: React.ReactNode // Replaces title/description in the tooltip
  color?: string // Badge background override
  onClick?: () => void // Click handler (fanned badges)
  href?: string // Navigate on click
  target?: "_blank" | "_self" // Link target. Default "_self"
}
```

### useActiveMarkers

`useActiveMarkers(items: ChartMarker[]): ChartMarker[]` returns the markers whose `date` falls on the same day as the hovered data point, or `[]` when nothing is hovered. Call it from a component rendered inside the chart (for example inside `ChartTooltip`).

### Simple custom marker

`ChartMarkers` always draws a circular badge. For a minimal annotation — a small diamond above the plot with a dashed guide — write your own layer with [`useChart`](/docs/charts/utility/use-chart). `xScale` maps the marker date to a pixel, and `innerHeight` is the plot height. Any SVG you return renders in the chart's plot space, so negative `y` sits in the top margin. Set the static `__isPostOverlay` flag on the component (the same flag `LineSeriesTerminalMarker` uses) so the layer renders outside the series reveal clip; otherwise the glyph above the plot top is clipped.

<ComponentPreview name="p-chart-markers-3" className="**:data-[slot=preview]:w-full" />

The demo also adds a small tooltip section that lists the diamond's title when the crosshair lands on its date — read `tooltipData` from `useChart` inside `ChartTooltip` children, the same way `useActiveMarkers` works.

## Tips

- **Leave room above the plot.** Badges sit 8px above the plot top, so they need `margin.top` of at least `size / 2 + 8` (22px at the default `size={28}`). Charts default to `margin.top = 40`; if you tighten margins, keep enough headroom or the badges and the fan-out arc will be cut off by surrounding layout.
- **Match dates to data.** Markers group and highlight by calendar day (`toDateString()`), so use dates that land on your data points' days.
- **Unique titles per day.** `title` keys the fanned badges, so give markers that share a date distinct titles.
- **Badge colors follow the theme.** Badges use `--color-background-muted` with a 10% `--color-foreground` border and `--color-foreground` text; the count badge inverts to `--color-foreground` / `--color-background`. Pass `color` on a marker to override its badge.
- **Custom glyphs stay passive.** A post-overlay layer like the diamond above sits on top of the chart's hover surface, so set `pointerEvents: "none"` to keep the crosshair working, and surface details through `ChartTooltip`.
