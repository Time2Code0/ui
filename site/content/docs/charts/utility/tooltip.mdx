## Usage

The ChartTooltip component provides hover interactions for charts. It must be used inside a chart component (`LineChart`, `AreaChart`, `BarChart`).

```tsx
import { LineChart } from "@/components/charts/line-chart/line-chart"
import { Line } from "@/components/charts/line-chart/line"
import { Grid } from "@/components/charts/chart-grid/grid"
import { ChartTooltip } from "@/components/charts/chart-tooltip/chart-tooltip"

;<LineChart data={data}>
  <Grid horizontal />
  <Line dataKey="value" />
  <ChartTooltip />
</LineChart>
```

## Anatomy

The tooltip has several visual components:

1. **Crosshair** - Vertical line that follows the cursor
2. **Dots** - A solid dot with a soft halo in the series color on each data point at the hovered position
3. **Tooltip Box** - Popover-style panel: a header row with the date / category, a full-width separator, then rows (color dot, muted label, right-aligned value)
4. **Date Pill** - Animated date ticker at the bottom

Each component can be shown/hidden independently.

## Animation

The tooltip features smooth animations:

- **Tooltip panel** - By default the panel eases with `damping={20}`. Set `matchCrosshair` to share the crosshair spring, or tune lag with `damping` (`0`–`100`) or `boxSpringConfig`.
- **Crosshair** - Spring physics for snappy following (`springConfig`)
- **Crosshair style** - Solid by default; pass `indicatorDasharray="4,4"` (or any SVG dash pattern) for a dashed line.
- **Tooltip Box** - Scale/fade in, fade out on leave (`exit`), flip detection (`boxSpringConfig`). Under `prefers-reduced-motion` the panel jumps to position and skips the scale; the opacity fade remains
- **Date Pill** - Slot machine-style number animation
- **Dots** - Follow the crosshair spring; the core and halo spring open on hover

All animations use motion/react for fluid, natural movement.

```tsx
<ChartTooltip
  indicatorDasharray="6,4"
  damping={60}
  indicatorColor="var(--color-chart-2)"
/>
```

## Theming

The tooltip box is styled like the other popovers: `var(--color-background)` panel, `text-foreground` with `foreground-muted` labels, a `border`, `rounded-xl` and a soft `shadow-lg/5`. The crosshair and dots default to `var(--color-foreground)` and the series color. Pass `backgroundColor` or `panelStyle` to override the panel, e.g. for a translucent blurred panel.

To match the built-in header in custom `content`, use `TooltipHeader`:

```tsx
<ChartTooltip
  content={({ point }) => (
    <>
      <TooltipHeader>{String(point.label)}</TooltipHeader>
      <div className="px-3.5 py-3 text-sm">…</div>
    </>
  )}
/>
```
