## Usage

Sparklines are single-element charts. Pass `data` and a `dataKey` — no axes, grid or tooltip to configure.

```tsx
import {
  AreaSparkline,
  BarSparkline,
  LineSparkline,
} from "@/components/charts/sparkline/sparkline"

<LineSparkline data={rows} dataKey="value" />
<AreaSparkline data={rows} dataKey="value" fill="gradient" />
<BarSparkline data={rows} dataKey="value" barRadius={2} />
```

- **Sizing:** omit `width` to fill the parent; `height` defaults to **32**. Every responsive sparkline on the page shares one `ResizeObserver`. Pass a fixed `width` to skip measuring entirely.
- **Animation:** the enter animation is on by default (`animate`). Lines draw in along their stroke, areas wipe in, bars grow from the baseline. When `data` changes, the path morphs to the new values over 500ms (`dataTransitionDuration`), like the main charts — written straight to the DOM, so no React re-render per frame. With `prefers-reduced-motion: reduce` the enter becomes a short fade and data changes snap.
- **Hover highlight:** like the main line and area charts, hovering fades the series to `inactiveOpacity` (0.5) and re-strokes the segment around the hovered point at full strength; the bright segment springs as you move. Bars fade every bar except the focused one (`inactiveOpacity`, 0.4). Turn the line/area highlight off with `showHighlight={false}`.
- **Hover:** a crosshair (`"dashed"` by default) and a dot spring to the nearest point, with the same spring as the main charts' tooltip (`hoverTransition={false}` to snap; reduced motion always snaps). Springs only exist while a sparkline is hovered. There is deliberately no tooltip — read the hovered value with `useSparklineHover` and render it wherever you like.

## Hovered values

`useSparklineHover` lifts hover state out of the chart. Spread `sparklineProps` onto a sparkline and read `datum` or `index`:

```tsx
const hover = useSparklineHover<Row>()
const shown = hover.datum ?? rows.at(-1)

<span>{shown.value}</span>
<AreaSparkline data={rows} dataKey="value" {...hover.sparklineProps} />
```

## Hover feel

The crosshair and dot spring between points with the same spring as the main charts' tooltip. Pass only the values you want to change to `springConfig` — higher `stiffness` feels snappier, lower `damping` bouncier — or set `hoverTransition={false}` to snap straight to each point. The series fade and highlight still animate either way. Reduced motion always snaps.

```tsx
<LineSparkline data={rows} dataKey="value" />
<LineSparkline data={rows} dataKey="value" springConfig={{ stiffness: 600, damping: 45 }} />
<LineSparkline data={rows} dataKey="value" hoverTransition={false} />
<BarSparkline data={rows} dataKey="value" hoverTransition={false} />
```

## Migrating

| Recharts | TanStack Charts | Sparkline |
| --- | --- | --- |
| `<LineChart data><Line dataKey="v" dot={false} /></LineChart>` | `lineY(rows, { y: "v" })` | `<LineSparkline data dataKey="v" />` |
| `<AreaChart data><Area dataKey="v" /></AreaChart>` | `areaY(rows, …)` + `lineY(rows, …)` | `<AreaSparkline data dataKey="v" />` |
| `<BarChart data><Bar dataKey="v" /></BarChart>` | `barY(rows, { y: "v" })` | `<BarSparkline data dataKey="v" />` |
| `isAnimationActive` | `svgAnimation` / `motion()` | `animate` |
| `type="monotone"` | `curve` | `curve="monotone"` |
| `ResponsiveContainer` / `responsive` | `width` / `height` | omit `width` |
