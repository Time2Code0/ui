  SpinnerEllipsis,
} from "@/components/ui/loading"
```

```

## API Reference

All indicators render with `role="status"`, `aria-label="Loading"` and `data-slot="spinner"`, and inherit their color from `currentColor`. Size them with `size-*` utilities.

### Spinner

Eight-bar spinner that rotates in discrete steps. Accepts all `svg` props. Used internally by `Button` for its `loading` state.

### SpinnerCircle

Circular arc spinner. Accepts all `svg` props.

### SpinnerCircleFilled

Circular arc spinner rendered on top of a faded track. Accepts all `svg` props.

### SpinnerEllipsis

Three pulsing dots. Accepts all `div` props; dots are sized with `size-2`.
