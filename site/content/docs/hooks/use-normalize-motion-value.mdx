Turns a Motion value into regular React state. Use it when you need to render a Motion value as text or pass it to code that doesn't understand Motion values.

## Installation

<InstallationTabs name="use-normalize-motion-value" />

## Usage

```tsx
import { useNormalizeMotionValue } from "@/hooks/use-normalize-motion-value"

function ScrollProgress() {
  const { scrollYProgress } = useScroll()
  const progress = useNormalizeMotionValue(scrollYProgress)

  return <span>{Math.round(progress * 100)}%</span>
}
```

The component re-renders on every change of the Motion value, which can be once per frame. For animations, keep using the Motion value directly with `motion` components and only normalize values you actually need in render.

## API Reference

```tsx
function useNormalizeMotionValue<T>(value: MotionValue<T>): T
```

| Parameter | Type             | Description               |
| --------- | ---------------- | ------------------------- |
| `value`   | `MotionValue<T>` | The Motion value to read  |

Returns the current value of `value`, updated on every change.
